# GORUT-OUTBREAK AI v9

Platform investigasi epidemiologi/KLB untuk Gorontalo Utara.

## v9
- Offline-first
- Supabase/PostgreSQL online opsional
- Login Supabase Auth + role badge
- Disease Library + questionnaire engine
- Public survey URL per investigasi
- Alert SKDR → PE/KLB → kasus → kontak → spesimen → analisis → laporan
- RR, OR, CI 95%, chi-square p-value screening
- GIS kasus
- Export/import CSV dan project JSON
- PWA/service worker

## Status
v9 adalah prototype operasional dan belum menjadi sistem registri kesehatan produksi. Instrumen penyakit harus divalidasi terhadap formulir/pedoman Kemenkes yang berlaku sebelum penggunaan resmi.
