# GORUT-OUTBREAK AI v37 — Automated PE/KLB Report Generator

## Fokus
v37 menghubungkan data investigasi aktif dengan draft laporan PE/KLB otomatis.

### Fitur
- Generate Draft Otomatis untuk laporan PE/KLB.
- Mengisi narasi berbasis dataset aktif: jumlah kasus, klasifikasi, kematian, kontak, spesimen, kunjungan, dan pola onset.
- Rekomendasi awal berbeda untuk penyakit prioritas.
- Narasi etiologi dibuat konservatif dan tidak menyatakan etiologi/KLB tanpa bukti.
- Draft tetap dapat diedit sebelum dicetak/ekspor.
- Export TXT juga membawa ringkasan data otomatis.

## Prinsip keselamatan epidemiologi
Hasil otomatis merupakan decision-support, bukan diagnosis, penetapan KLB, atau pengganti verifikasi epidemiologis/laboratorium. Definisi kasus, baseline, ketentuan program, dan kewenangan penetapan harus tetap diperiksa.
