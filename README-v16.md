# GORUT-OUTBREAK AI v16

## Fokus
v16 menetapkan format **Laporan Penyelidikan Epidemiologi Kejadian Luar Biasa (KLB)** berdasarkan struktur contoh PDF yang diberikan pengguna sebagai template operasional di dalam aplikasi.

Struktur laporan:
1. Ringkasan Eksekutif
2. Pendahuluan
3. Metode Penyelidikan
4. Hasil Penyelidikan
5. Pembahasan
6. Kesimpulan
7. Rekomendasi Tindak Lanjut
8. Daftar Pustaka
9. Pengesahan

## Integrasi data
Laporan menarik data dari investigasi aktif, kasus, kontak, spesimen/laboratorium, kunjungan lapangan, dan hasil analisis 2x2 yang tersimpan.

## Prinsip keamanan interpretasi
- Sistem tidak mengarang data yang tidak tersedia.
- Denominator populasi yang tidak tersedia ditampilkan sebagai `—`.
- Kesimpulan etiologi/KLB tidak ditetapkan otomatis.
- Analisis statistik diberi status alat bantu dan perlu validasi epidemiolog.
- Definisi kasus operasional dan rekomendasi dapat diisi/ditinjau tim investigasi.

## Output
- Pratinjau HTML di aplikasi
- Cetak / Simpan sebagai PDF melalui browser
- HTML mandiri
- TXT
