# GORUT-OUTBREAK AI v43 — Open Access Epidemiological Command Center

## Perubahan akses
- Registrasi pengguna ditiadakan.
- Login aplikasi ditiadakan.
- Konfirmasi pembayaran ditiadakan.
- Biaya/subscription ditiadakan.
- Durasi akses/expiry ditiadakan.
- Aplikasi langsung membuka workspace operasional.

## Command Center v43
Menggabungkan ringkasan investigasi, kasus, kematian, spesimen, alert, koordinat/GIS, dan prioritas sinyal penyakit. Skor hanya decision-support dan bukan penetapan KLB atau diagnosis.

## Modul penelitian
Research Protocol Builder tetap tersedia dengan pemilihan penyakit/outcome, desain studi, populasi, sampling, variabel, definisi operasional, confounder, rencana analisis, etik, pendanaan, dan checklist pelaporan.

## Catatan backend
Versi ini beroperasi sebagai aplikasi open-access lokal. Integrasi backend autentikasi/subscription lama tidak digunakan dalam alur aplikasi.
