# GORUT-OUTBREAK AI v25 — Publication-Grade Statistics

v25 extends Research Studio with a publication-oriented analysis layer:
- crude 2x2 effect estimates (OR/RR according to design)
- multivariable logistic regression with adjusted OR, 95% CI and Wald p
- automatic analytic table output
- forest plot for adjusted OR
- complete-case sensitivity analysis for outcome/exposure
- stratified effect estimates for effect-modification review
- CSV export of publication estimates

Important: this remains a browser-side analytical prototype. Results must be checked against raw data and an independent validated statistical package before thesis, dissertation, official report, or publication use. Automatic output does not establish causality, and model assumptions, separation, collinearity, calibration, missing-data mechanisms, sampling design, clustering, matching, and survey weights require researcher/statistician review.
