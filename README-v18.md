# GORUT-OUTBREAK AI v19 — Command Center

## Fokus
v19 menambahkan Dashboard Command Center Dinkes di atas fondasi v17. Dashboard menyatukan alert, investigasi, kasus, kontak, spesimen/laboratorium, kunjungan lapangan, kesiapan data, kurva onset investigasi aktif, cakupan spasial, akses cepat, dan daftar investigasi terbaru.

## Komponen
- Alert aktif
- Investigasi berjalan
- Total kasus, konfirmasi, meninggal
- Kontak
- Spesimen pending
- Kunjungan lapangan belum sinkron
- Pipeline respons
- Kesiapan data investigasi aktif
- Kurva onset sederhana dari tanggal onset yang tersedia
- Ringkasan cakupan GPS
- Filter investigasi berdasarkan nama/tipe/status
- Akses cepat ke line listing, kontak, lab, analisis, chain of transmission, GIS, dan laporan PE/KLB

## Prinsip
Dashboard adalah situational-awareness dan decision-support. Grafik kurva sederhana bukan pengganti analisis epidemiologi tervalidasi. Angka hanya berasal dari data lokal yang tersedia; kekosongan data ditampilkan sebagai kekosongan.

## Laporan PE/KLB
v17 tetap menjadi basis format laporan formal dan lampiran. Paket laporan v19 menyimpan metadata versi v19.
