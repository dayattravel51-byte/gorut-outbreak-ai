# GORUT-OUTBREAK AI v48

## Research Automation — Application Data First

v48 memperkuat Research Studio agar variabel penelitian dapat ditemukan langsung dari record kasus investigasi aktif dan jawaban kuesioner (`case.answers`).

### Fitur
- Variable Dictionary otomatis dari data kasus + jawaban kuesioner.
- Pemilihan outcome dan exposure langsung dari variabel yang tersedia.
- Table 1 karakteristik data penelitian.
- Analisis bivariat 2x2 untuk outcome/exposure binary: OR, 95% CI, p-value, missing.
- Forest plot OR berbasis hasil bivariat.
- Provenance sumber data: investigasi aktif dan n kasus.
- Semua keluaran v48 menggunakan data aplikasi; dataset eksternal tidak digunakan oleh mesin v48.
- Tetap mempertahankan Research Studio, PE/KLB, GIS, dashboard lapangan/kontak, dan modul sebelumnya.

## Catatan metodologi
Output v48 adalah decision-support/analisis awal. Peneliti harus memeriksa coding, desain, sampling, matching/cluster, confounding, missing data, asumsi model, dan membandingkan hasil dengan perangkat statistik tervalidasi sebelum tesis/disertasi/publikasi atau keputusan program.
