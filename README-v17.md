# GORUT-OUTBREAK AI v17 — Basis Laporan PE/KLB

## Fokus
v17 memformalkan keluaran Laporan Penyelidikan Epidemiologi (PE/KLB) mengikuti struktur dan gaya contoh laporan KLB yang diberikan pengguna.

## Struktur laporan
1. Metadata laporan
2. Ringkasan Eksekutif
3. I. Pendahuluan
   - 1.1 Latar Belakang
   - 1.2 Tujuan Umum
   - 1.3 Tujuan Khusus
   - 1.4 Definisi Kasus Operasional
4. II. Metode Penyelidikan
   - 2.1 Desain Studi
   - 2.2 Populasi dan Sampel
   - 2.3 Pengumpulan Data
   - 2.4 Analisis Data
   - 2.5 Tim Investigasi
5. III. Hasil Penyelidikan
   - 3.1 Besaran Masalah
   - 3.2 Orang
   - 3.3 Waktu/kurva epidemik
   - 3.4 Tempat
   - 3.5 Kasus, kontak, spesimen, kunjungan lapangan
   - 3.6 Analisis epidemiologi
   - 3.7 Dugaan etiologi/diagnosis
6. IV. Pembahasan
7. V. Kesimpulan
8. VI. Rekomendasi Tindak Lanjut
9. Lampiran
   - Line listing kasus
   - Daftar kontak
   - Daftar spesimen/laboratorium
   - Kunjungan investigasi lapangan
10. Daftar pustaka
11. Pengesahan

## Output
- Pratinjau laporan
- Cetak / Simpan PDF melalui dialog print browser
- HTML
- TXT
- Paket data JSON untuk audit/arsip

## Prinsip data
- Angka dan daftar kasus berasal dari investigasi aktif.
- Tidak ada denominator populasi yang dibuat-buat.
- Jika data belum tersedia, laporan menandainya sebagai belum tersedia.
- Status KLB, etiologi, dan interpretasi akhir tetap divalidasi epidemiolog.
- Lampiran mengandung data sensitif dan hanya boleh dibagikan sesuai kewenangan.
