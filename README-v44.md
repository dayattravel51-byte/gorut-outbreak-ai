# GORUT-OUTBREAK AI v44

## Epidemiological Command Center

v44 builds on v43 Open Access and adds an operational command-center layer:
- 14-day onset trend
- 7-day vs previous 7-day signal
- case/death/pending specimen/open investigation/open alert metrics
- data completeness screening for address, onset, coordinates, and status
- action queue for alerts, investigations, specimens, geolocation, and data quality
- disease signal ranking
- quick navigation to affected modules

The score is decision-support only. It does not establish diagnosis, KLB, causality, source, or a validated prediction.

All prior Research Studio, disease-specific instruments, PE/KLB generator, P-T-W, GIS/RBI, and open-access behavior are retained.
